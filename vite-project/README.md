# PACMAN — простое объяснение проекта

Это небольшая браузерная игра в стиле Pac-Man. Игрок управляет жёлтым героем, собирает точки, избегает врагов и проходит два лабиринта. Этот документ объясняет проект простым языком — знать программирование заранее не обязательно.

## Как запустить игру

Для запуска нужны Node.js и npm:

```bash
npm install
npm run dev
```

Терминал покажет адрес сайта, обычно `http://localhost:5173`.

## Правила игры

- Герой двигается стрелками на клавиатуре или кнопками под полем.
- Нужно собрать все маленькие точки. Каждая даёт 10 очков.
- Большая жёлтая точка включает защиту на 7 секунд и даёт ещё 50 очков.
- В клетке большого бонуса также есть обычная точка, поэтому сейчас там начисляется всего 60 очков.
- Во время защиты враги голубые. За пойманного врага даётся 200 очков, а враг возвращается на старт.
- Без защиты столкновение отнимает жизнь. В начале даются 3 жизни.
- После всех точек открывается следующий уровень. Всего уровней два.

## Файлы проекта

### `src/main.jsx`

Точка запуска. Файл находит на странице место `root` и помещает туда игру `Pacman`.

Импорты `BrowserRouter`, `Routes`, `Route` и `StrictMode` сейчас не используются и на игру не влияют.

### `src/Pacman.jsx`

Главный файл: карты, правила, движение, враги, очки, жизни и внешний вид.

### `src/index.css`

Подключает Tailwind CSS. Почти всё оформление игры сейчас написано прямо в `Pacman.jsx`.

### `index.html`

Начальная HTML-страница. В ней есть пустое место `root`, куда React вставляет игру.

### `package.json`

Список библиотек и команд:

- `npm run dev` — запустить игру для разработки;
- `npm run build` — собрать готовую версию;
- `npm run preview` — посмотреть собранную версию;
- `npm run lint` — проверить код на возможные ошибки.

## Основные константы

Константа — это значение с понятным именем, которое не меняется во время игры.

- `CELL = 32` — размер клетки лабиринта в пикселях.
- `PACMAN_SIZE = 24` — размер героя.
- `ENEMY_SIZE = 24` — размер врага.
- `TICK = 115` — герой делает шаг примерно каждые 115 миллисекунд. Чем меньше число, тем быстрее игра.
- `POWER_TIME = 7000` — защита работает 7000 миллисекунд, то есть 7 секунд.
- `START_LIVES = 3` — начальное количество жизней.

## Карты уровней — `LEVELS`

`LEVELS` хранит два уровня. У каждого есть:

- `id` — номер;
- `name` — английское название;
- `subtitle` — русское описание;
- `theme` — цвета;
- `map` — лабиринт.

Карта записана обычным текстом:

- `#` — стена;
- `.` — проход с точкой;
- `P` — старт игрока;
- `E` — старт врага.

Каждая строка текста — горизонтальный ряд, а каждый символ — одна клетка.

## Направления — `DIRS`

`DIRS` описывает четыре стрелки: `ArrowUp`, `ArrowDown`, `ArrowLeft`, `ArrowRight`.

У направления есть:

- `x` — сдвиг по горизонтали;
- `y` — сдвиг по вертикали;
- `angle` — угол поворота героя.

Например, движение вправо прибавляет 1 к `x`, не меняет `y` и поворачивает героя на 0 градусов.

## Цвета — `ENEMY_COLORS`

Массив хранит цвета трёх врагов: розовый, голубой и фиолетовый. Цвет выбирается по номеру врага.

## Все обычные функции

### `parseLevel(level)`

Переводит текстовую карту в данные, понятные игре:

1. Разделяет строки на клетки.
2. Находит `P` и запоминает старт игрока.
3. Находит `E` и запоминает старты врагов.
4. Заменяет `P` и `E` обычными проходами с точками.
5. Собирает список всех точек.
6. Выбирает примерно центральный свободный проход для большого бонуса.
7. Возвращает сетку, точки, бонус, игрока и максимум трёх врагов.

Координата хранится как текст, например `5:3`: клетка 5 по горизонтали и 3 по вертикали.

### `keyOf(x, y)`

Соединяет координаты в одну запись. Например, `keyOf(5, 3)` возвращает `"5:3"`. Так проще искать и удалять точки.

### `isWall(grid, x, y)`

Проверяет, является ли клетка стеной. Место за пределами карты тоже считается стеной, поэтому персонажи не уходят за границу.

### `canMove(grid, x, y)`

Проверяет, разрешено ли перейти в клетку: координаты должны быть внутри карты, а впереди не должно быть стены.

### `distance(a, b)`

Считает, сколько горизонтальных и вертикальных шагов разделяет две клетки. Стены при этом не учитываются. Результат нужен врагам для выбора пути.

### `getEnemyMove(enemy, player, grid, enemyIndex)`

Выбирает следующий шаг врага. Сначала проверяет четыре направления и убирает варианты со стеной. Затем:

- враг №1 идёт в доступную клетку ближе всего к игроку;
- враг №2 обычно отдаляется, но иногда идёт случайно;
- враг №3 всегда выбирает случайный свободный путь.

Если двигаться некуда, враг остаётся на месте.

### `Pacman()`

Главная функция игры. Она хранит текущее состояние, запускает таймеры, проверяет правила и создаёт всё, что видно на экране.

Команда `export default Pacman` в конце разрешает подключить игру в `main.jsx`.

## Что хранит игра — `useState`

`useState` можно представить как коробку с текущим значением. Когда значение меняется, React автоматически обновляет экран.

- `level` — текущий уровень: `0` означает первый, `1` — второй.
- `levelData` — подготовленная карта текущего уровня.
- `player` — текущие координаты игрока.
- `direction` — направление движения сейчас.
- `queuedDirection` — направление, которое игрок хочет выбрать следующим. Если сразу повернуть нельзя, игра запоминает нажатие.
- `enemies` — текущие позиции врагов.
- `pellets` — набор ещё не собранных точек.
- `power` — положение большого бонуса. После сбора становится пустым.
- `powerMode` — включена ли защита: `true` означает «да», `false` — «нет».
- `powerUntil` — точное время окончания защиты.
- `score` — очки.
- `lives` — жизни.
- `status` — состояние: `playing`, `gameover` или `won`.
- `levelMessage` — сообщение между уровнями.

## Дополнительные значения

- `grid` — сетка лабиринта;
- `rows` и `cols` — количество рядов и столбцов;
- `boardWidth` и `boardHeight` — размер поля в пикселях;
- `theme` — цвета уровня;
- `powerSeconds` — оставшиеся секунды защиты;
- `pelletItems` — координаты точек для рисования.

`useMemo` запоминает `pelletItems` и пересчитывает их только при изменении точек.

## Функции управления игрой

### `resetLevel(nextLevel, keepScore)`

Заново готовит выбранный уровень. Герой, враги, точки, направление и бонус возвращаются в исходное состояние. `keepScore` решает, сохранять ли очки; по умолчанию они сохраняются.

### `restartGame()`

Полностью начинает игру заново: включает первый уровень, обнуляет очки, возвращает 3 жизни, состояние `playing` и убирает сообщение.

### `nextLevel()`

Если есть следующий уровень, показывает сообщение, ждёт одну секунду и загружает новый лабиринт. Очки и жизни сохраняются. После последнего уровня включает состояние `won`.

`useCallback` запоминает эти функции, чтобы React без необходимости не создавал их заново при каждом обновлении экрана.

## Как работают игровые процессы — `useEffect`

`useEffect` запускает действие при старте игры или изменении нужных данных.

### Нажатия клавиш

Игра слушает клавиатуру. Нажатая стрелка записывается в `queuedDirection`. При закрытии игры обработчик удаляется из памяти.

### Движение игрока

Каждые 115 миллисекунд игра пытается передвинуть героя. Сначала проверяется новое направление. Если там стена, герой продолжает старое движение. Если и старый путь закрыт, он остаётся на месте.

### Движение врагов

Примерно каждые 230 миллисекунд для каждого врага вызывается `getEnemyMove`, и враг выбирает следующую клетку.

### Сбор точек

После движения проверяется клетка игрока:

- обычная точка удаляется и даёт 10 очков;
- бонус исчезает, даёт 50 очков и защиту на 7 секунд;
- последняя обычная точка завершает уровень.

### Таймер защиты

Пока защита работает, игра каждые 100 миллисекунд проверяет время. После 7 секунд защита выключается.

### Столкновение

Если герой и враг находятся в одной клетке:

- с защитой игрок получает 200 очков, а враг возвращается на старт;
- без защиты теряется жизнь, а герой и все враги возвращаются на старт;
- собранные точки и очки после потери жизни сохраняются;
- после последней жизни включается `gameover`.

## Как рисуется экран

`Pacman` возвращает JSX — запись, похожую на HTML. Она описывает элементы экрана:

1. Название и номер уровня.
2. Счёт, жизни и оставшиеся точки.
3. Игровое поле.
4. Синие стены для клеток `#`.
5. Маленькие точки.
6. Большой бонус, если он не собран.
7. Героя в координатах `player`.
8. Врагов в координатах `enemies`.
9. Счётчик защиты.
10. Сообщение о завершении уровня.
11. Экран победы или поражения.
12. Подсказки и кнопки управления.

Положение задаётся через `left` и `top`. Координата клетки умножается на `CELL`, поэтому объект попадает в правильное место. `transition` делает движение между клетками плавным.

Кнопка `PLAY AGAIN` вызывает `restartGame`. Экранные стрелки меняют `queuedDirection` так же, как клавиатура.

## Вся игра по шагам

1. Браузер открывает страницу.
2. `main.jsx` запускает `Pacman`.
3. `parseLevel` читает первую карту.
4. React рисует стены, точки, героя и врагов.
5. Игрок выбирает направление.
6. Таймеры передвигают героя и врагов.
7. После каждого шага проверяются точки, бонусы и столкновения.
8. Изменения автоматически показываются на экране.
9. После всех точек загружается следующий уровень.
10. После второго уровня показывается победа, а после потери трёх жизней — поражение.
